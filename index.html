OFF

🩺 Relational Migration Doctor

V15.0.72

Công cụ đọc-only để kiểm tra dữ liệu sau migration: so sánh JSON legacy với relational tables, tìm dữ liệu thiếu/trùng/mồ côi, kiểm tra kho sữa ledger, Sổ sức khỏe, Tiêm chủng, Timeline. Công cụ này không sửa/xóa dữ liệu.

--Checks
--Passed
--Warnings
--Errors

Read-only: Doctor chỉ kiểm tra dữ liệu và trả báo cáo. Nếu còn lỗi đỏ, chưa nên bật RelationalReadMode.

Chưa chạy Doctor.

🔁 Relational Delta Sync

V15.0.72

Đồng bộ phần dữ liệu legacy JSON phát sinh sau lần migration đầu tiên sang relational tables. Công cụ dùng ID ổn định + upsert chống trùng, không xóa meyeube_sync.data và chưa đổi app sang đọc/ghi table mới.

--Total delta
--Care thiếu
--Changed
SAFENo duplicate

Khuyến nghị: Nếu Doctor báo lệch do app còn ghi JSON legacy, chạy Preview Delta rồi Chạy Delta Sync. Sau đó chạy Doctor lại, mục tiêu đạt 25/25 trước khi bật RelationalReadMode.

Chưa kiểm tra delta sync.

🧭 Relational Read Mode

Mặc định tắt. Bật sau khi Doctor = 100 và Delta = 0.

TẮT
TẮTChưa kiểm tra
Read onlyChưa ghi table
DoctorBắt buộc passed
DeltaBắt buộc = 0

An toàn dữ liệu: bản này chỉ đọc thử từ relational tables. Thêm/sửa/xóa vẫn ghi JSON legacy/Cloud Queue như hiện tại. Nếu app phát sinh dữ liệu mới, Read Mode sẽ tự chặn/fallback cho đến khi Boss chạy Delta Sync và Doctor lại.

Chưa kiểm tra RelationalReadMode.

✍️ Relational Write Queue

Mặc định tắt. Chỉ bật sau khi tất cả thiết bị đã sẵn sàng dùng relational tables.

TẮT
TẮTChưa kiểm tra
0Local queue
Dual-safeJSON vẫn backup
LockTuần tự theo family

An toàn dữ liệu: bản này thêm hàng đợi ghi relational nhưng mặc định tắt. Khi bật, thao tác lưu vẫn ghi local/JSON backup để rollback, đồng thời đưa snapshot vào queue và đẩy tuần tự sang relational tables. Không nên bật nếu còn thiết bị chưa cùng version.

Chưa kiểm tra RelationalWriteQueue.

🚀 Đẩy dữ liệu chính thức

Dùng sau khi tất cả thiết bị đã bật ReadMode + RelationalWriteQueue. Công cụ này kiểm tra lần cuối rồi chốt relational tables làm nguồn dữ liệu chính thức.

CHƯA CHỐT
--Local modes
--Local queue
--Server queue
--Primary state

Nguyên tắc: chỉ chốt khi ReadMode/WriteQueue đang bật trên thiết bị này, local queue = 0, server queue không lỗi, Doctor passed và Delta = 0. JSON legacy vẫn được giữ để rollback/backup, chưa xóa.

Chưa kiểm tra đẩy dữ liệu chính thức.
